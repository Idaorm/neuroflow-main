How to Read the Motion Signals

Quaternions (Q0–Q3)

Describe head orientation in 3D space. Values are normalized to the range [-1, +1].

ChannelAxisAt Rest
Q0Scalar (W)≈ 1.0
Q1X — nodding≈ 0
Q2Y — turning≈ 0
Q3Z — tilting≈ 0

Still head: Q0≈1 and Q1/Q2/Q3≈0. During movement, Q0 may decrease while the other components increase.

Accelerometer (ACC)

Measures linear head acceleration across three axes using raw Cortex API motion values.

ChannelDirection
ACCXForward / Backward
ACCYLeft / Right
ACCZUp / Down (gravity)

Flat traces generally indicate little movement, while sharp peaks correspond to faster changes. The chart scale adapts automatically.

Magnetometer (MAG)

Measures the surrounding magnetic field using raw Cortex API motion values.

ChannelDirection
MAGXMagnetic field X
MAGYMagnetic field Y
MAGZMagnetic field Z

Values can change gradually as the head rotates and may also be affected by nearby metal objects or electromagnetic interference.

Note: this page reads live motion data shared by charts.html through localStorage. Keep charts.html open during the session to receive real-time updates.
